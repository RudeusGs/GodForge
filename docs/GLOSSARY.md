# Glossary

| Term | Definition |
|---|---|
| Analysis profile | Versioned configuration that selects validation rules, parser capabilities, health rules and optional AI behavior. |
| Analysis run | Durable execution record for one repository revision and analysis configuration. |
| Artifact | Generated object stored outside PostgreSQL, such as report PDF, preview image or large graph payload. |
| Asset | Non-source project content such as texture, audio, font, model, video or other resource. |
| Asset manifest | Repository-tracked metadata that maps a logical Godot path to an Asset Vault object and visibility policy. |
| Asset Vault | MinIO-backed service layer for independently permissioned and versioned assets. |
| Commit SHA | Immutable Git revision identifier used as the analysis revision key. |
| Deterministic parser | Parser whose output is reproducible for identical input and parser version. |
| Finding | A versioned health, security or maintainability issue with evidence and severity. |
| Forgejo | External Git engine used for repository hosting, clone, fetch, push, branches and commits. |
| Godot validation | Security and structural checks proving that a revision is a supported Godot project before analysis. |
| Health score | Rule-engine-derived score; never directly generated by AI. |
| Hosted repository | Repository provisioned and hosted by Forgejo through GodForge. |
| Incremental analysis | Re-analysis of changed files and their dependency impact instead of the entire revision. |
| Linked repository | External HTTPS Git repository connected to a GodForge project. |
| Organization | Tenant boundary containing projects, members, policies and quotas. |
| Project | Product-level collaboration unit linked to one primary repository and optional Asset Vault. |
| Repository snapshot | Persisted inventory and metadata for one commit SHA. |
| Rule set version | Immutable version of deterministic health rules and weights. |
| Signed URL | Short-lived object-storage URL issued only after authorization. |
| Worker | Background process that consumes durable jobs and performs repository, parser, analysis, AI and artifact work. |
